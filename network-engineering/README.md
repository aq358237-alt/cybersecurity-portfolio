# Network Engineering Portfolio

A collection of self-directed network engineering labs focused on enterprise routing, switching, WAN availability, and secure site-to-site connectivity.

> **Project scope:** These are simulation/lab exercises. They demonstrate configuration practice, verification, and troubleshooting—not paid employment or production network deployments.

## Projects

| Project | Focus | Technologies |
|---|---|---|
| [01 — Dual-ISP WAN Redundancy](./01-dual-isp-wan-redundancy/README.md) | Resilient enterprise Internet connectivity and automatic failover | eBGP, iBGP, OSPF, BGP Local Preference, IP SLA, object tracking |
| [02 — Secure DMVPN Phase 2](./02-secure-dmvpn-phase2/README.md) | Hub-and-spoke VPN with dynamic spoke-to-spoke paths | mGRE, NHRP, IKEv1, IPsec, OSPF |
| [03 — Enterprise Routing & Switching](./03-enterprise-routing-switching/README.md) | Campus switching and dynamic routing practice | VLANs, trunks, STP, EtherChannel, OSPF, EIGRP, BGP |

## Lab tools

- GNS3
- Cisco Packet Tracer
- VMware Workstation

## Documentation approach

Each project page explains the problem, objectives, design approach, technologies, verification plan, and troubleshooting considerations. Configuration files, topology diagrams, and command-output evidence will be added as they are collected and reviewed.

## Important notes

- Configurations and outputs should be sanitized before publication. Never commit passwords, pre-shared keys, private certificates, or personal/customer information.
- Verification commands are listed as a checklist; only attach outputs that were actually captured from the lab.
- Cisco training and preparation are not the same as holding an official Cisco certification.
